# 🧠 1. What is Sales Analysis?

**Sales Analysis** means studying sales data to understand how products are performing.

For example:

```text
Product → Price → Quantity Sold → Revenue
```

Revenue can be calculated using:

```text
Revenue = Price × Quantity
```

Example:

```text
Dog Food
Price = 1200
Quantity = 2

Revenue = 1200 × 2
Revenue = 2400
```

---

# 📦 2. What is Inventory Analysis?

**Inventory Analysis** means checking the available stock of products.

For example:

```text
Product       Stock
Dog Food        2
Cat Food        3
Treats          5
Toy             4
```

If stock is very low, the business may need to restock the product.

For this practice:

```text
Low Stock = Quantity < 5
```

# 💰 5. Product Revenue

Revenue formula:

```text
Revenue = Price × Quantity
```

Python:

```python
products = ["Dog Food", "Cat Food", "Treats", "Toy"]

prices = [1200, 900, 300, 500]

quantities = [2, 3, 5, 4]

for i in range(len(prices)):
    revenue = prices[i] * quantities[i]

    print(products[i], revenue)
```

### Output

```text
Dog Food 2400
Cat Food 2700
Treats 1500
Toy 2000
```

---

# 💵 7. Total Revenue

Now let's calculate the revenue generated by all products.

```python
products = ["Dog Food", "Cat Food", "Treats", "Toy"]

prices = [1200, 900, 300, 500]

quantities = [2, 3, 5, 4]

total = 0

for i in range(len(prices)):
    total_amount = prices[i] * quantities[i]

    total = total + total_amount

print("Total Revenue:", total)
```

### Output

```text
Total Revenue: 8600
```

---

# 🔄 9. Accumulator Pattern

The following pattern is very important:

```python
total = 0

for i in range(len(prices)):
    amount = prices[i] * quantities[i]

    total = total + amount
```

This is an **accumulator pattern**.

It means we start from `0` and keep adding values.

This pattern can be used for:

- Total revenue
- Total sales
- Total quantity
- Total expenses
- Total transactions
- Total marks

# ⚠️ 11. Low-Stock Products

Now let's identify products with low stock.

Business rule:

```text
Low Stock = Quantity < 5
```

Python:

```python
products = ["Dog Food", "Cat Food", "Treats", "Toy"]

quantities = [2, 3, 5, 4]

for i in range(len(products)):
    if quantities[i] < 5:
        print("Low Stock:", products[i])
```

### Output

```text
Low Stock: Dog Food
Low Stock: Cat Food
Low Stock: Toy
```

`Treats` has quantity `5`, so it is not considered low stock because the condition is:

```python
quantity < 5
```

# 📉 18. Finding Lowest Revenue

We can also find the product with the lowest revenue.

```python
products = ["Dog Food", "Cat Food", "Treats", "Toy"]

prices = [1200, 900, 300, 500]
```

# 📋 19. Complete Sales Analysis Program

Now let's combine everything.

```python
products = ["Dog Food", "Cat Food", "Treats", "Toy"]

prices = [1200, 900, 300, 500]

quantities = [2, 3, 5, 4]

total_revenue = 0
total_stock = 0
low_stock_count = 0
expensive_count = 0

highest_revenue = 0
highest_product = ""

lowest_revenue = prices[0] * quantities[0]
lowest_product = products[0]

for i in range(len(products)):

    revenue = prices[i] * quantities[i]

    print("Product:", products[i])
    print("Price:", prices[i])
    print("Quantity:", quantities[i])
    print("Revenue:", revenue)

    total_revenue = total_revenue + revenue
    total_stock = total_stock + quantities[i]

    if quantities[i] < 5:
        print("Status: Low Stock")
        low_stock_count = low_stock_count + 1

    if prices[i] >= 1000:
        print("Category: Expensive")
        expensive_count = expensive_count + 1

    if revenue > highest_revenue:
        highest_revenue = revenue
        highest_product = products[i]

    if revenue < lowest_revenue:
        lowest_revenue = revenue
        lowest_product = products[i]

    print()

print("Total Revenue:", total_revenue)
print("Total Stock:", total_stock)
print("Low Stock Products:", low_stock_count)
print("Expensive Products:", expensive_count)
print("Highest Revenue Product:", highest_product)
print("Highest Revenue:", highest_revenue)
print("Lowest Revenue Product:", lowest_product)
print("Lowest Revenue:", lowest_revenue)
```

# ❌ 30. Common Beginner Mistakes

### Mistake 1 — Forgetting Indexes

Incorrect:

```python
revenue = prices * quantities
```

For the current learning approach, process the related values using their indexes:

```python
revenue = prices[i] * quantities[i]
```

---

### Mistake 2 — Wrong `range()`

Incorrect:

```python
for i in len(products):
```

Correct:

```python
for i in range(len(products)):
```

---

### Mistake 3 — Wrong Comparison

If the rule is:

```text
Quantity < 5
```

write:

```python
if quantities[i] < 5:
```

Not:

```python
if quantities[i] > 5:
```

---

### Mistake 4 — Forgetting the Accumulator

Incorrect:

```python
for i in range(len(prices)):
    total = prices[i] * quantities[i]
```

This only keeps the current product's revenue.

For total revenue:

```python
total = 0

for i in range(len(prices)):
    amount = prices[i] * quantities[i]
    total = total + amount
```
